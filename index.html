HOW TO WEEKEND

周末的三种过法

同样的 48 小时，三种完全不同的节奏。先想清楚你要哪一种。

01

慢游派

一天只安排一件事。早上在一个街区吃两小时早餐，下午找一间茶馆坐到日落。

适合：苏州 / 成都 / 景德镇

02

暴走派

两天走完三万步。博物馆、老城、夜市全部打卡，回程的高铁上睡到终点站。

适合：泉州 / 天津 / 杭州

03

看海派

目的地只需要有海、有风、有一张能坐很久的长椅。行程表上只写「日出」和「发呆」。

适合：阿那亚 / 厦门 / 大理
